Godot Mining Prototype "Astrobor"

Prototype for a 2D isometric mining/flotilla sim (Godot 4, GDScript).

How to open
- Install Godot 4.x
- Open this folder as a project in Godot
- Open `res://scenes/Main.tscn` and run

What is included
- Scenes: `scenes/Main.tscn`, `scenes/Asteroid.tscn`, `scenes/Drone.tscn`, `scenes/Flotilla.tscn`
- Scripts: `scripts/` contains a minimal resource system, drone AI, and UI hookup

Notes
- Visuals are placeholder shapes and Labels for prototyping. Tweak values in scripts for balance.
